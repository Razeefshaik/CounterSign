CounterSign: the AI proposes, the code countersigns (PayPal AI Hackathon)

**Description**

CounterSign is the safety layer between AI agents and PayPal. The agent can read and propose. It cannot move money. Deterministic code checks every proposal against 16 named rules, the owner signs anything that sends money out with a passkey, and only then does one adapter make the PayPal call.
